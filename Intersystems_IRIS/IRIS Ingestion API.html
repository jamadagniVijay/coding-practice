IRIS Ingestion API

IRIS Ingestion API v1.0

REST API for ingesting data into InterSystems IRIS and querying stored records. This API runs parallel to the file-based ingestion pipeline.

Authentication: This API uses unauthenticated access with the %All application role. The web application /api/ingestion dispatches to Sample.REST.IngestionAPI in the USER namespace.
Ingestion
POST /ingest Ingest data with auto-generated filename ▶

Accepts any content body and ingests it into the database. The system generates a filename automatically based on the current timestamp (e.g. api-upload-2026-11-05_14-30-00).

Request Body
body* any Raw content to ingest. Set Content-Type to match the payload (text/plain, application/json, etc.).
Response (201 Created)
{ "status": "ok", "message": "Data ingested successfully", "filename": "api-upload-2026-11-05_14-30-00" }

Try it out

POST /ingest/{filename} Ingest data with a custom filename ▶

Accepts any content body and ingests it, using the provided filename as the record label.

Path Parameters
filename* string Custom name for the ingested record (e.g. sensor-data.json).
Request Body
body* any Raw content to ingest.
Response (201 Created)
{ "status": "ok", "message": "Data ingested successfully", "filename": "sensor-data.json" }

Try it out

Records
GET /records List all ingested records ▶

Returns a JSON array of all ingested records, ordered by ReceivedAt descending (newest first). Does not include the full content body.

Response Schema
FieldTypeDescription
idintegerUnique record identifier
fileNamestringName assigned during ingestion
contentTypestringMIME type of the ingested data
sourcestringPipeline that created the record
receivedAtstringTimestamp (YYYY-MM-DD HH:MM:SS)
Example Response
{ "records": [ { "id": 1, "fileName": "api-upload-2026-11-05_02-34-45", "contentType": "text/plain", "source": "REST API", "receivedAt": "2026-11-05 02:34:45" } ] }

Try it out

GET /records/{id} Get a single record with content ▶

Returns a single record by ID, including the full content body. Returns 404 if the record does not exist.

Path Parameters
id* integer Record ID from the database.

Data Model
SCHEMA Sample.Entity.IngestedRecord Database table schema ▶

The Sample_Entity.IngestedRecord SQL table stores every record ingested through the REST API pipeline.

ColumnTypeDescription
IDinteger (PK)Auto-generated primary key
FileNamevarchar(256)Original or generated filename
Contentvarchar(max)Full text content of the payload
ContentTypevarchar(128)MIME type from the HTTP request
Sourcevarchar(128)Pipeline origin label (default: "REST API")
ReceivedAttimestampWhen the data was received
SQL Query Example
SELECT ID, FileName, ContentType, Source, ReceivedAt FROM Sample_Entity.IngestedRecord ORDER BY ReceivedAt DESC
